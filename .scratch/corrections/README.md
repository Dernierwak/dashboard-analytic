# Corrections

Les réparations trouvées en chemin : des bugs du produit tel qu'il tourne
aujourd'hui, et de la maintenance. **Rien ici n'est une décision** — chaque
ticket dit ce qui est faux et ce qui le prouve ; on le corrige, on vérifie, on
le passe à `Status: resolved`.

Ce chantier existe pour que les cartes `wayfinder` ne portent que des
questions à trancher. Une réparation trouvée en travaillant une carte atterrit
ici, pas sur la carte.

Les tickets sont dans `issues/`, mêmes conventions que partout
(`docs/agents/issue-tracker.md`). Ils sont indépendants : on les prend dans
l'ordre qu'on veut.
